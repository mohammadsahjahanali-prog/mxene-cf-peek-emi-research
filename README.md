# Machine Learning Prediction of EMI Shielding in Lightweight MXene/CF–PEEK Aerospace Composites
This repository contains the literature review, methodology, experimental modeling notebook, manuscript, and presentation slides for predicting X-band Electromagnetic Interference Shielding Effectiveness ($\text{EMI SE}$) in $\text{Ti}_3\text{C}_2\text{T}_x$ MXene / Carbon Fiber–PEEK composites.
## Repository Contents
* **Research Paper:** [`paper.md`](paper.md) — Complete manuscript with abstract, introduction, methodology, results, discussion, conclusion, and references.
* **Presentation Deck:** [`presentation.pptx`](presentation.pptx) — 6-slide summary covering the aerospace shielding problem, novelty, methodology, results, and takeaways.
* **Experiment Notebook:** [`experiment.ipynb`](experiment.ipynb) — Jupyter Notebook for data cleaning, percolation feature engineering, and model evaluation (Extra Trees vs. Ridge Regression).
* **Methodology:** [`methodology.md`](methodology.md) — Experimental matrix, percolation feature definitions, and evaluation metrics.
* **Literature Review:** [`literature_review.md`](literature_review.md) — Summaries of key peer-reviewed studies on MXene EMI shielding and thermoplastic aerospace composites.
* **Figures:** [`figures/`](figures/) — Matplotlib/Seaborn charts used in the manuscript and presentation.
